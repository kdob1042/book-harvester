# つながりビューワー — 2026-10-02

## 範囲

既存メニューの「つながりを見る」から、保存された問いの親子関係と記録を読む専用ビューワーを開く。ホームは既存のまま。追加ライブラリ、DB変更、AI呼び出し、書き込み操作はない。`app.js`、ログイン、取り込み、統合の実行処理は変更しない。

- 問いの階層を上から下へ配置し、異なる深さの統合と共有された記録を保持する。同じ記録は一つのノードから複数の問いへ接続する。
- 最新mainの掘り下げ関係にも対応。現在の一覧APIは統合と掘り下げを型なしで返すため、初期表示は「親子関係」とする。詳細の `children` / `parents` / `drilldown_children` / `drilldown_parents` で確認できた辺だけを「統合元」「掘り下げた問い」と区別する。推測で関係を作らない。
- 問いを選ぶと、その問いの現在の材料を追加表示。統合入力の版と一致した記録だけを統合元の実線にし、それ以外の材料は破線で表示する。
- 詳細には任意の問い内容、保存済み知見、条件・反例、記録の原文・訂正本文・メモ・原ファイル、保存済みの関連理由を表示する。原文と訂正後の本文を区別する。
- 検索は読み込み済みデータに対するローカル検索。ズーム、ドラッグ、タッチのピンチ、キーボード操作に対応。スマホでは詳細を下部に表示する。

## データ・安全性

`GET /api/themes`、`GET /api/themes/:id`、`GET /api/captures/:id` のみを使用。元ファイルリンクも既存の認証付きGETルートを使用する。JSONは `textContent` で描画し、ユーザー文字列をHTMLとして解釈しない。取得情報は開いている間のメモリーだけに保持し、閉じると破棄する。閉じた後の遅延レスポンス、選択順が入れ替わったレスポンスは描画しない。

現在の材料APIを正本とし、過去の入力スナップショットだけから消えた記録を復活させない。取得した記録の版が違う場合や404時は古い辺を除く。更新された根拠は保存時点の知見として警告する。認証エラーは再ログイン確認を案内し、空データ・ネットワーク障害・再試行を用意する。サーバー全体の公開範囲判定を変更するPRではない。

描画は最大300ノード。上限に達した場合は表示件数を明示し、検索に一致したノードを優先する。問いの材料は既存APIの上限である最新100件まで。未選択の問いの材料は先読みせず、未取得記録の全文検索は行わない。循環データは再帰せず停止して警告する。

`public/index.html` はCSSと入口モジュールの読み込みのみ追加。Service Workerはシェル版と追加アセット一覧のみ更新し、元ファイルキャッシュ、認証、IndexedDB契約を変えない。ビューワーのデータ表示はオンライン前提。
