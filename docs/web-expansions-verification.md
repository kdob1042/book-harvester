ハイライトは `book-harvester/highlights-v1`（sourceとitems、各項目はtext/origin/source|user|ai、note、locator）および日本語/英語のKindle `My Clippings.txt` のHighlight/Noteに対応する。未対応サービスを対応済みとは表示しない。外部AI回答は資料の確定事実へ変換しない。書誌照合が落ちても原資料と知見は読める。

外部取得先は運営者が信頼するホストの許可一覧で制限する。DNS応答の公開IP判定、リダイレクト毎の再検査、資格情報・特殊ポート・私設IP・大きすぎる本文を拒否する。任意ホストのDNSピン留めを実装したものではない。追加先は `RESEARCH_ALLOWED_HOSTS` に完全一致ホストを設定する。本人メモ・本の全文は検索へ送らず、フォームで確認した問いと対象期間だけを送る。

- `npm test`：39件。実Workerコード、SQLite/D1アダプター、R2/Queueアダプターを使う。プロバイダーは明示モックのみ、未指定の外部通信は拒否する。

- Cloudflare向けdry runとローカルマイグレーションを実施。Wrangler/workerdの実行でD1認証、非公開R2アップロード、Queue経由のunpdf解析、同期API、取り込み削除も成功。本番リソース・秘密は未設定。

PDFの合成ファイルは実パーサーで取り出す。標準フォントデータ未指定の警告が残り、合成ASCIIテキストの抽出は成功した。日本語フォント・図版・縦書き・レイアウトの読み取り品質は未検証で、読めないページは本文が取得できた扱いにしない。
